# Conquista — downloads para Windows

Jogo de estratégia com territórios, dados 3D e partidas privadas entre amigos.

## Instalar

[**Baixar o instalador para Windows 64 bits**](https://github.com/naipsnoob/conquista-releases/releases/latest/download/MareDeNacar.Conquista-win-Setup.exe)

1. Execute o instalador.
2. Abra **Conquista** pelo atalho na área de trabalho ou no menu Iniciar.
3. O launcher verifica as novas versões no GitHub ao abrir, baixa e aplica atualizações antes de iniciar o jogo. Sem internet, a versão instalada continua disponível. Você também pode escolher **Jogar sem atualizar**.

Unity, GitHub CLI e .NET não precisam ser instalados separadamente. O pacote inclui o jogo completo e o runtime do launcher. Este instalador de testes ainda não possui certificado de assinatura digital.

[Ver versões e notas de atualização](https://github.com/naipsnoob/conquista-releases/releases)

## Partidas privadas

Os downloads são públicos. As salas do jogo continuam privadas e exigem a aprovação do anfitrião. Todos os participantes devem usar a mesma versão do jogo.

## Dados e atualizações

Saves, configurações e dados de reconexão ficam fora da pasta substituída pelas atualizações. O launcher aplica atualizações com o jogo fechado e não interrompe partidas em andamento. A desinstalação está disponível nos aplicativos instalados do Windows.

## Conteúdo deste repositório

Este espaço contém informações de distribuição e arquivos anexados a Releases. O projeto Unity, credenciais, saves pessoais, comprovantes de reconexão e logs de testes não são publicados aqui.
