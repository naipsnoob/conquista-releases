# Conquista — downloads para Windows

Repositório de distribuição do jogo Conquista, usado nos testes com amigos.

## Downloads

Os instaladores e pacotes de atualização serão disponibilizados na página **Releases** deste repositório. Ainda não há instalador com atualização automática publicado.

Quando o instalador estiver disponível, instale o jogo uma vez e abra pelo atalho criado. O launcher verificará as atualizações ao iniciar. Atualizações não devem interromper partidas em andamento.

## Partidas privadas

Este repositório é público, mas as salas do jogo continuam privadas e exigem a aprovação do anfitrião. Todos os participantes devem usar a mesma versão do jogo.

## Conteúdo deste repositório

Este espaço contém apenas informações de distribuição e arquivos de release. O projeto Unity, credenciais, saves, comprovantes de reconexão e logs de testes não são publicados aqui.
